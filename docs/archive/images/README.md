# Archived Museum Photographs

Photographs of the museum and its exhibits that are **not currently used on the site**. They
were added on 2026-03-29 alongside the original museum page, as a batch from which only some
were chosen. They are kept here rather than deleted: they document the museum's exhibits and
displays as they stood in early 2026, which is worth preserving for a historical society even
when no page links to them.

Files here are **not deployed**. Anything in `docs/` is outside the build, so these are
preserved in version control without being served. Previously they sat in `public/`, which
meant every one was uploaded to the CDN on each deploy while being referenced by nothing.

## To put one back on the site

Move it to `src/assets/`, import it, and render it with `<Image />` — see the Images section
of the [README](../../../README.md). Do not move it back to `public/`; files there skip
optimization entirely.
